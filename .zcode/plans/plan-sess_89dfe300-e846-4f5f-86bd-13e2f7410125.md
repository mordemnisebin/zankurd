## ZanKurd Kapsamlı Geliştirme Planı — 4 Alan, 3 Faz

### Faz 1: Hızlı Kazanımlar (1-2 hafta)

**A) Kürtçe TTS (flutter_tts)**
- pubspec.yaml'daki yorum satırı aktifleştirilecek
- QuizScreen'e "dinle" butonu (soru + şirove seslendirme)
- Android Google TTS motoru Kürtçe locale testi
- iOS fallback: "iOS'ta yakında" mesajı
- Hız/volume ayarları

**B) Web + Büyük Ekran (Flutter Web)**
- `flutter build web` aktifleştirme
- ResponsiveWrapper breakpoint'leri genişletme (tablet 1024px, desktop 1440px)
- React prototipi emekli etme
- RevenueCat Web Billing

**C) İçerik Takviyesi**
- Paradigma: 30+ soru
- Siyaset: 30+ soru  
- Muzîk: 20+ soru
- curated_question_bank.dart güncelleme
- Tam Kürtçe şiroveler

**D) RevenueCat Monetizasyon (purchases_flutter)**
- Paket ekleme, yapılandırma
- Premium entitlement: reklamsız, detaylı istatistik, sınırsız joker
- Paywall ekranı
- Coin paketleri RevenueCat'e taşıma

### Faz 2: Derinleştirme (2-4 hafta)
- Soranî lehçe desteği
- Onboarding akışı
- Sosyal paylaşım kartı
- Oda içi chat
- AI soru taslağı pipeline

### Faz 3: Büyüme (1-3 ay)
- Canlı turnuva + push
- Eğitim kurumu sınıf modu (B2B)
- Mini oyun formatları

### Teknik Riskler
- TTS: iOS Kürtçe desteği sınırlı → cloud TTS fallback
- RevenueCat: Standart, düşük risk
- Web: Supabase + Firebase web desteği mevcut
- Responsive: Pattern zaten kodda var
